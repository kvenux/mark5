# 性能基准实测数据

本文档记录 **Mark 5**、**MarkText 0.24** 与 **VS Code 1.145** 在同一台 Windows 11 机器上的同口径实测数据。

## 测试条件

- **统一文档**：
  - 窗口 1：`01-architecture-mermaid.md`（3 张 Mermaid 图表：flowchart / sequence / state + 40 张大表 + 40 段 Rust 代码块）
  - 窗口 2：`02-massive-spec.md`（约 70 KB，160 节技术规格书）
- **内存口径**：`Win32_PerfFormattedData_PerfProc_Process.WorkingSetPrivate`（汇总整棵进程树真实独占物理内存，不重复计入共享 DLL）。
- **CPU 口径**：稳态后 5 秒窗口的平均单核占比（`100%` = 占满 1 个逻辑核）。

## 综合对比

| 指标 | **Mark 5**（Tauri v2） | **MarkText 0.24**（Electron 45） | **VS Code 1.145**（Electron） |
| --- | :---: | :---: | :---: |
| **软件体积（单版本）** | **6.96 MB**（1 文件） | 382.9 MB（984 文件） | 1,006.6 MB（3,274 文件） |
| **单开内存（活跃）** | **156.5 MB**（7 进程） | 338.0 MB（5 进程） | 381.2 MB（10 进程） |
| **双开内存（活跃）** | **197.0 MB**（7 进程） | 545.4 MB（6 进程） | 1,375.2 MB（15 进程） |
| **多开 1 窗增量** | **+40.5 MB** | +207.4 MB | +994.0 MB |
| **双开后台/最小化** | **80.3 MB**（自动回收） | 287.8 MB | — |
| **冷启动累计 CPU（单/双窗）** | **2.56 / 4.11 CPU-s** | 3.77 / 6.19 CPU-s | — |
| **双开待机 CPU** | **0.74%** | 1.89% | 5.40% |
